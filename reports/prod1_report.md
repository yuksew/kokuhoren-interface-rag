## 追記: SQLite 化（2026-11-01）
`src/build_db.py` で確定版を `db/interface_spec.sqlite`（8.9 MB）に入れた。中身は文書4・表237・行7,774・列ごとの値11,982・注記1,443。

| テーブル | 中身 |
|---|---|
| `documents` | 文書（版）。manifest の内容 |
| `pages` | 印刷ページ番号・ページ下の注記 |
| `spec_tables` | 論理的な表（ページをまたぐ表は結合済み） |
| `items` | 行。PDF のページ・項番・属性・桁数・内容・必須・人の修正の有無 |
| `item_values` | 行の列ごとの値（必須対応表の ◎○△、識別・周期など）。列キー（様式番号など）で引ける |
| `item_notes` | 行に付いた「※n」注記の本文 |
| `items_fts` | 全文検索（FTS5 trigram、3文字以上の部分一致） |
| `v_items` | 文書・版・ページを結合したビュー（出典表示用） |
