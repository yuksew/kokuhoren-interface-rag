## 疑問点（判断が必要）
1. **全文が無い資料をどう入れるか。**
   - 介護の告示: 法令等データベースの溶け込み版を使う。
   - 障害の留意事項: 2段の「改正後」の欄を取り出す。
   - 介護の留意事項・障害の告示: 新旧対照表を日付つきで積み重ね、新しいものを優先して答えさせる。
   - 自前で溶け込み版を作るのは手間と誤りの危険が大きい。
2. **介護の記載要領の正本が2つある**（WAM 確定版と厚労省 Vol.1489）。インタフェース仕様書と同じ R8.5.25 確定版に同梱された WAM 版が、仕様書と版がそろう。
3. **Q&A の範囲**: 現行の系統（介護 R6 Vol.1〜18 と R8 系、障害 R6・R8 系）だけにするか、令和3年度以前でまだ有効な問いまで含めるか。
4. **正誤表**: 障害 Q&A VOL.1・2 の正誤表は、正誤を反映した版を使うか、正誤表も別に入れるか。
5. **次の改定サイクル**: R9（総合事業のサービス種類の変更、R8.10.6 その1）が始まっている。台帳に「将来版」として登録だけしておくか。
6. **障害の明細書の記載要領**: 現行版が見つからない（平成18年の通知の写しだけ）。記載例とハンドブックで代わりにする。
7. **障害の告示の番号**: 自治体の転載に「令和8年告示第7号」とあるが、厚労省・こども家庭庁のページは「第5号」。第5号を正とした。
8. **介護の記載要領の通知番号**: 正しくは平成13年11月16日老老発第31号（依頼文の「第0428001号」は誤り）。地域密着型の留意事項は老老発第0331018号。

## 判断と取得結果（2026-11-01）
- 疑問点 1〜3・5 は推奨案のとおりに決めた（全文があれば全文、無ければ新旧対照表を日付つきで積み重ねる／介護の記載要領は WAM 確定版／Q&A は現行の系統だけ／R9 は登録だけ）。4 は正誤表を別の資料（category: errata）として入れることにした。6〜8 は上のとおり。
- 台帳は `sources/rules_manifest.yaml`（94件、うち将来版1件）。`uv run python src/fetch.py --manifest sources/rules_manifest.yaml` で 93件・約95MB を取得し、sha256 を書き戻した。再実行するとすべてスキップされる。
- **介護の告示（法令等データベース）**: 8本とも R8 告示第87号の内容（訪問介護の処遇改善加算(Ⅰ)イ 1000分の270、居宅介護支援・介護予防支援の 1000分の21 など）が本文に入っている。ただし末尾の「改正文」の一覧は令和4年で止まっているので、版の判断には本文を使う。1ページだけの告示はページ数の表示が無い（fetch.py で対応）。
